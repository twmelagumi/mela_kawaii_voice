# 熱千めら 聲音圖鑑

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 聲音頁（投稿的聲音片段、搜尋、標籤） |
| `songs.html` | 歌單頁（讀 `songs.json`），要改歌單頁只改這個檔 |
| `timeline.html` | 編年史頁（直播、發布、紀念日的時間線） |
| `assets/style.css` | 各頁共用的外觀（顏色、字體、版面） |
| `assets/common.js` | 各頁共用的程式（語言切換、共用文字、頁內播放器） |
| `clips.json` | 固定收錄的片段（可以一直保留，網站會和 Google 試算表的片段合併顯示） |
| `songs.json` | 「歌曲」分頁的歌單，由管理者自己編輯後上傳 |
| `timeline.json` | 編年史的固定事件（出道日、生日、重要直播…） |
| `timeline_auto.json` | 編年史自動抓到的 YouTube 直播／影片（GitHub Actions 自動更新，不用手動改） |
| `scripts/update_timeline.py` | 自動抓 YouTube 的程式 |
| `.github/workflows/update-timeline.yml` | 每天早上 6 點（台灣時間）執行上面的程式 |

網站片段有兩個來源，會自動合併、去掉重複：

1. `clips.json`
2. Google 試算表裡標成「通過」的投稿（設定方法見下面）

## Google 表單投稿設定（只要做一次）

### 1. 建立 Google 表單

到 https://forms.google.com 建立空白表單，標題例如「熱千めら 聲音投稿」。
依序新增下面這些問題。**題目文字請照抄**，網站是靠題目裡的關鍵字（網址、開始、結束、標題、台詞、標籤、備註、日期）認欄位的，括號裡的說明可以改。

| 題目 | 題型 | 必填 | 回應驗證 |
|---|---|---|---|
| YouTube 或 X 網址 | 簡答 | ✔ | 驗證 A |
| 開始時間（時:分:秒，例如 0:01:23） | 簡答 |  | 驗證 B |
| 結束時間（時:分:秒，例如 0:01:30） | 簡答 |  | 驗證 B |
| 標題 | 簡答 | ✔ |  |
| 台詞（選填） | 簡答 |  |  |
| 標籤（選填） | 核取方塊：笑聲、尖叫、怪聲、口癖、名台詞、歌聲、可愛、崩潰、語錄，並開啟「其他」 |  |  |
| 備註（選填） | 段落 |  |  |
| 直播日期（選填） | 日期 |  |  |

回應驗證（在題目右下角「⋮」→「回應驗證」開啟）：

- **驗證 A**：規則運算式 → 包含 → `youtube\.com|youtu\.be|x\.com|twitter\.com`
- **驗證 B**：規則運算式 → **包含** → `^\d{1,2}:\d{2}:\d{2}$`，錯誤訊息填：請用 時:分:秒，例如 0:01:23
  （規則開頭有 `^`、結尾有 `$`，所以選「包含」就等於整格都要符合格式。千萬不要選「不符合」，那會反過來擋掉正確的時間。）

表單「設定」裡：

- 「收集電子郵件地址」選 **不收集**。
- 如果之後被灌垃圾投稿，再開「限制回覆次數為 1 次」（填寫者需要登入 Google）。

### 2. 連結到 Google 試算表

1. 表單上方切到「回覆」→ 按「連結至試算表」→ 建立新試算表。
2. 打開試算表，回應會出現在「表單回應 1」分頁，第 1 列是題目，A 欄是時間戳記，B～I 欄是 8 個問題。
3. 在 **J1** 輸入 `狀態`。
4. 把「狀態」做成下拉式選單（選項只填 `通過`、`退回`，不要填「狀態」）：
   - 回應是「表格」樣式時（標題列有 ▼）：點「狀態」標題右邊的 **▼** →「編輯欄類型」→「下拉式選單」。
   - 一般試算表：選取 **J2** 以下的儲存格（不要包含 J1 標題）→「資料」→「資料驗證」→ 下拉式選單。
5. （可略過）C、D 欄的時間會顯示成 `00:32:58` 這種格式，網站讀得懂，不用改成純文字。

### 3. 建立「公開」分頁

1. 左下角「＋」新增分頁，改名為 `公開`。
2. 在「公開」分頁的 **A1** 貼上：

   ```
   =IFERROR({'表單回應 1'!A1:I1; FILTER('表單回應 1'!A2:I, '表單回應 1'!J2:J="通過")}, '表單回應 1'!A1:I1)
   ```

   這個分頁只會顯示狀態是「通過」的投稿，待審和退回的都看不到。

### 4. 把「公開」分頁發佈成 CSV

1. 「檔案」→「共用」→「發佈到網路」。
2. 第一個選單選 **公開**（不要選「整份文件」），第二個選單選 **逗號分隔值 (.csv)**。
3. 按「發佈」，複製出現的網址（結尾是 `output=csv`）。
4. 試算表本身的共用設定維持「限制」，不要把編輯連結給別人。

### 5. 把兩個網址填進網站

打開 `index.html`，找到這兩行，填入網址後存檔，再上傳到 GitHub：

```js
const SUBMIT_URL = "";      // ← 表單的「傳送」→ 連結（https://forms.gle/…）
const SHEET_CSV_URL = "";   // ← 第 4 步複製的 CSV 網址
```

（也可以把兩個網址給 Claude，請它幫你填好。）

## 日常審核

1. 打開試算表的「表單回應 1」分頁。
2. 確認片段沒問題，就在 J 欄選 **通過**；不收錄就選 **退回**。
3. 大約 5 分鐘後，網站就會自動出現新片段，不用重新上傳任何檔案。
4. 想修正投稿內容（打錯字、時間不準），直接改「表單回應 1」裡那一格就好。

## 第一次上線到 GitHub Pages

1. 到 https://github.com 登入 → 右上角「＋」→ **New repository** → 選 **Public** → **Create repository**。
2. 點 **uploading an existing file**，把 `index.html`、`clips.json` 拖進去 → **Commit changes**。
3. **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選 `main`、`/ (root)` → **Save**。
4. 等 1～2 分鐘，網址是 `https://你的帳號.github.io/repository名稱/`。

## 小提醒

- 直接雙擊 `index.html` 會讀不到片段、YouTube 也會出錯。請用 GitHub Pages 的網址看，或在資料夾執行 `python -m http.server` 後開 http://localhost:8000 。
- 換到其他網路空間時，一樣把 `index.html` 和 `clips.json` 放在同一個資料夾就好。

## 「歌曲」分頁（songs.json）

網站上方有「聲音／歌曲」兩個分頁，歌曲分頁是獨立的 `songs.html`。歌單不開放投稿，內容全部來自 `songs.json`。
直接分享歌單頁的網址：`https://你的網址/songs.html`（舊的 `#songs` 連結會自動轉過去）

### 格式

`songs.json` 是一個清單，每首歌一組 `{ }`，組和組之間用逗號隔開，最後一組後面**不要**加逗號：

```json
[
  {
    "title": "歌名",
    "artist": "原唱歌手",
    "category": "clip",
    "url": "https://www.youtube.com/watch?v=影片ID",
    "start": "1:02:03",
    "end": "1:06:10",
    "streamDate": "2026-09-30"
  },
  {
    "title": "第二首歌名",
    "artist": "原唱歌手",
    "category": "cover",
    "url": "https://www.youtube.com/watch?v=影片ID",
    "start": "1:07:30",
    "streamDate": "2026-09-30"
  }
]
```

| 欄位 | 必填 | 說明 |
|---|---|---|
| `title` | ✔ | 歌名 |
| `artist` |  | 原唱歌手 |
| `category` |  | 分類：`original`（原創曲）、`cover`（翻唱）、`clip`（歌回）、`other`（其他）。沒填就算 other |
| `pick` |  | 填 `true` 就會出現在歌單頁上方的「★ 推薦」區塊（可以推薦好幾首，照 songs.json 的順序排） |
| `singers` |  | 演唱者，合唱曲才需要填。寫成 `["熱千めら","宙科そぴあ"]` 或 `"熱千めら / 宙科そぴあ"` 都可以；沒填就當作めら一個人唱。歌單上可以點名字，只看跟那個人合唱的歌 |
| `url` | ✔ | YouTube 網址（watch、youtu.be、live 都可以；網址裡有 `t=` 會當成開始時間） |
| `start` |  | 開始時間，`"1:02:03"` 或秒數 `3723` |
| `end` |  | 結束時間，填了播放器會在這裡自動停 |
| `streamDate` |  | 配信日期，`"2026-09-30"` 或 `"2026/9/30"` |
| `note` |  | 備註（目前只用在搜尋） |

### 更新方式

1. 用記事本或 VS Code 編輯 F:\MELA\songs.json。
2. 到 GitHub repository →「Add file」→「Upload files」，上傳覆蓋 → Commit。
3. 約 1 分鐘後網站更新。

格式打錯（少逗號、多逗號、引號沒成對）時，歌曲分頁會顯示「還沒有收錄歌曲」。可以把檔案內容貼到 https://jsonlint.com 檢查，或把歌單（歌名、歌手、網址、時間）直接給 Claude，請它幫你產生 songs.json。

### 今日推薦（聲音頁）

聲音頁的標籤下方有「★ 今日推薦」區塊，顯示試算表裡標記為推薦的片段：

1. 在 `mela_voice_input` 分頁的 **K 欄** 標題填 `推薦`，欄類型設成「核取方塊」（也可以直接填 `v`、`1`、`是`）。
2. 「公開」分頁 A1 的公式改成（多帶出 J、K 欄，網站會自動略過「狀態」欄）：

   ```
   =IFERROR(VSTACK(mela_voice_input!A1:K1, FILTER(mela_voice_input!A2:K, mela_voice_input!J2:J="通過")), mela_voice_input!A1:K1)
   ```

3. 想推薦的片段打勾，取消就拿掉。約 5～10 分鐘後網站更新。
4. `clips.json` 裡的片段也可以加 `"pick": true`。
5. 訪客在搜尋或篩選標籤時，推薦區塊會暫時收起來。

## 「編年史」分頁（timeline.html）

一條時間線，顯示直播、發布、紀念日。預設只顯示最近一年（含即將到來的紀念日），可以切換年份、月份、種類。

### 資料來源（後面的會蓋過前面的）

1. **`timeline_auto.json`**：GitHub Actions 每天台灣時間早上 6 點，從 めら 頻道的 RSS 抓最近 15 支影片（アソビ★まわり隊！ 團體頻道的影片手動新增）。
   - 直播要播完才加入；Shorts 不收；首播的 MV 算「發布」；日期用日本時間。
   - 只會新增、不會刪除：以前抓到的影片會一直留在 `timeline_auto.json`，不會被最近 15 支覆蓋。最近 15 支每次會重新確認，種類／日期／標題有變就更新。
   - 標題最後的【ホロライブ/アソビ★まわり隊！/熱千めら】這類固定標籤會自動拿掉。想馬上抓：GitHub → **Actions** → **Update timeline** → **Run workflow**。
   - 要加／拿掉頻道：改 `scripts/update_timeline.py` 最上面的 `CHANNELS`。
2. **`timeline.json`**：手動維護的固定資料。
3. **Google 試算表「編年史」分頁**：日常新增、修改自動抓到的內容（設定見下面）。

同一支影片（同網址）算同一個事件，後面的來源只覆蓋有填的欄位。`songs.json` 裡同一支影片的歌會自動列在那個事件底下；沒有對應事件的歌會依 `streamDate` 自動長出一個「這天唱的歌」。

### timeline.json 格式

```json
{ "date": "2026-10-01", "type": "stream", "title": "はじめての歌枠", "url": "https://www.youtube.com/watch?v=…", "note": "說明（可以換行）" }
```

| 欄位 | 說明 |
|---|---|
| `date` | 日期 `"2026-10-01"` |
| `type` | `stream` 直播／`collab` 合作／`release` 發布／`anniv` 紀念日 |
| `title` | 標題 |
| `url` | YouTube 網址（有網址就會顯示縮圖，點了開 YouTube） |
| `note` | 說明 |
| `yearly` | `true` → 每年同一天自動出現。標題含「生日／誕生／birthday」或加 `"count": false` 時只顯示原標題，否則顯示「N 週年」 |
| `debut` | `true`（只要一個）→ 週年顯示成「出道 N 週年」 |

### Google 試算表「編年史」分頁設定

1. 在投稿用的試算表新增分頁「編年史」，第一列填標題（順序不拘）：`日期`、`種類`、`標題`、`網址`、`說明`、`每年`、`隱藏`
2. **種類**填 直播／合作／發布／紀念日（日文 配信／コラボ／リリース／記念日 也可以）。
3. **改自動抓到的內容**：填同一個網址＋想改的欄位（例如標題改短、加說明）。
4. **隱藏**打勾（或填 v、1）→ 那個網址的事件不顯示。
5. **每年**打勾 → 每年自動出現（生日、週年）。
6. 「檔案 → 共用 → 發佈到網路」→ 選「編年史」分頁、格式選 CSV → 複製網址，填進 `timeline.html` 的 `TIMELINE_CSV_URL`。
7. 改完約 5 分鐘網站更新。

### 注意

- GitHub Actions 會自己 commit `timeline_auto.json`，本機 push 前要先 `git pull --rebase`。
